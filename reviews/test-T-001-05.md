### AC: Passwords are hashed with argon2id

- **command:** `npm test` → `src/server/auth/password.test.ts:60-119`
- **expected:** With `HP_HASH_TEST=1`, `hashPassword("a-secret-pass")` starts with `$argon2id$` and encodes `{ id: "argon2id", m: 8, t: 1, p: 1 }`. A padded password produces a different hash. `verifyPassword` accepts the exact password, rejects the padded string against the unpadded hash, rejects the trimmed padded password against the padded hash, and rejects `"wrong-password"`. Two hashes of the same password differ and both verify. `$argon2i$…`, `$argon2d$…`, `$argon2id$not-a-digest`, and `""` verify as false. With `HP_HASH_TEST` unset, the encoded params are `{ id: "argon2id", m: 65536, t: 3, p: 1 }`, the password verifies, and a trailing space does not.
- **actual:** those five password tests passed, including the 493ms strong-parameter hash. Production sets `type: argon2.argon2id` on both parameter objects (`src/server/auth/password.ts:13`, `:22`) and passes that object to `argon2.hash` (`src/server/auth/password.ts:41`). `verifyPassword` returns false unless the stored string starts with `$argon2id$` (`src/server/auth/password.ts:51-52`).
- **file:line:** `src/server/auth/password.test.ts:60-76`, `:78-86`, `:88-103`, `:105-119`
